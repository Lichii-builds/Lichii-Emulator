# Lichii Switch 2 Emulator

**Lichii Switch 2 Emulator** build 75 rides the nx2 rail off Eglantine. The notes map which lichii nx2 changes land, why litchi and liichi searches resolve upstream, and how the msvc build brings dejitter, hid input, and an updater. Games, keys, and firmware are not included.

## First launch
1. Extract the archive and run lichii.exe.
2. Point it at keys, firmware, and a game you already own.
3. The updater lane pulls the next build.
4. Notes in `files/notes/`.
